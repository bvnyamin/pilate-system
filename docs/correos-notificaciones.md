# Correos de Aledra Pilates

Los avisos usan una plantilla HTML adaptable a móvil, con una versión de texto
alternativa para clientes de correo que no muestran HTML. El puente de Apps
Script envía ambas versiones con Gmail.

## Tipos de correo

### Nueva solicitud de perfil

**Asunto:** Aledra Pilates: nueva solicitud de perfil

**Ejemplo:** “Hay un perfil por revisar. Nombre informado: Camila Ejemplo.
Revisar solicitud.” El correo no incluye respuestas ni antecedentes médicos;
la administradora inicia sesión para revisar la ficha en el sistema.

En **Notificaciones**, el botón **Ejemplo: nueva solicitud** manda una muestra
con este formato y un nombre ficticio.

### Mensualidad pendiente

**Asunto:** Aledra Pilates: mensualidades pendientes 10/2026

**Ejemplo:** “Hay 2 mensualidades con saldo pendiente después del día 7”,
seguido por clienta, plan, período y saldo. Incluye un botón para revisar los
pagos pendientes.

El botón **Ejemplo: aviso de pago** manda dos filas de muestra. El asunto y el
pie indican que es un ejemplo y que los saldos no son reales.

### Prueba de correo

**Asunto:** Aledra Pilates: prueba de correo

**Ejemplo:** “El correo de Aledra está listo”. Confirma el envío y enlaza a
Notificaciones. No incluye datos de clientas.

El diseño usa una cabecera sobria en tono ciruela, fondo marfil, acento coral,
contenido de lectura breve y botones de acción visibles. Los datos de ejemplo
de este documento son ficticios.
